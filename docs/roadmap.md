# Roadmap

**轻量、纯 CPU、自部署的 OCR webui（RapidOCR onnx · PP-OCRv6）。**
支柱：纯 CPU 优先 · 后台任务队列 · 可视化校对。

## 现行计划

| 优先级 | 项 | 说明 |
|---|---|---|
| T1.5 | 更新 README 截图 | 当前截图为旧版 UI |
| T2 | 撤销/批量替换 | 校对深化：纠错撤销栈；系统性识别错误（己/已、0/O）全局替换 |
| T3 | 后端错误消息本地化 | 中文界面下错误弹窗为英文，需错误码体系 |
| T3 | API 调用示例 | curl / Python 片段补进 api.md |

## 按需（真实场景出现再做）

图片旋转（横拍输入出现时）· 多栏阅读顺序（双栏输出交错时）· 双任务对比（档位切换后的 A/B 需求）· 移动端整体验证

## 暂不计划

表格结构识别 / 字段提取（需布局大模型，超出纯 CPU 定位）· 多用户隔离（单用户产品）· 任务历史管理界面（核心能力已随 P1 交付）· UI 动效打磨（进度系统已解决根本问题）

## 已交付（摘要）

P0 + P1 已于 2026-08 收官；P2 已交付：档位热切换（tiny/small/medium，模型预置镜像）、队列管理面（置顶分区/逐项启停/全部暂停/抢占取消/重启恢复）、可搜索 PDF（glyf 字体子集化）、DOCX 导出。明细见 git 历史与 README「Fork 亮点」。
